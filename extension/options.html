Lecture Scribe

Settings

Lecture Scribe records a lecture, transcribes it on your own computer and builds study prompts for the AI tool you choose. These settings are stored only in this browser.

1. About your studies

Used to tailor the Study prompts. All optional, and you can change them any time.

"auto" lets Whisper detect the language of each 30 second part. Pick a language if the lecture is always in one language: it is more reliable.

2. Local server

Start the server first (see the README). It prints a token the first time it runs; you can show it again with python server.py --show-token inside local-server.

3. Colour

4. Microphone

Needed only for in-person lectures. Chrome asks once.

5. Optional: export folder

Off by default. If you choose a folder, every transcript is also saved there as a Markdown file. If that folder is inside Google Drive, OneDrive or Dropbox, that service uploads it to your cloud account, which is how you can add the files to NotebookLM from Drive. Leave this empty to keep everything only in local-server/data.

6. Advanced and optional: live Google Docs

Writes each transcript part into a Google Doc of yours while you record. It needs a small script in your own Google account (see docs/OPTIONAL_GOOGLE_DOCS.md). Skip this unless you want it.
